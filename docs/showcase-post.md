# Showcase post

The content for the nashvilleaiclub.com `naic_showcase` post lives in `showcase-post.html`:
four worked examples in D -> A order (team sheet, red card, overload, pressing block), each with the
problem, setup steps, the soccer/factory toggle, the measured numbers, and what the model cannot tell
you. `src="IMG:sf-*.png"` placeholders are swapped for the uploaded media URLs when the post is built;
the screenshots themselves are the `sf-*.png` files in this folder, captured by `tools/capture-shots.mjs`.
